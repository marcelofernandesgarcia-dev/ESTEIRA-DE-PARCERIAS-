# Pasta de Capacitações

Esta pasta é destinada aos arquivos de suporte e materiais didáticos que serão utilizados nos cards de capacitações do sistema SGP.

## Como utilizar:
1. Adicione os arquivos (PDFs, PPTXs, documentos, etc.) nesta pasta.
2. Eles estarão disponíveis para acesso e download público no navegador através da rota base `/capacitacoes/nome-do-arquivo.ext`.
3. Atualize os links correspondentes nos cards de capacitação do front-end.
